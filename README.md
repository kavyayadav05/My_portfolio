## 🌐 How to Deploy on GitHub Pages

1. Navigate to your repository settings on GitHub: `https://github.com/kavyayadav05/My_portfolio/settings/pages`
2. Under **Build and deployment** -> **Source**, select **Deploy from a branch**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your portfolio website will be live in a couple of minutes at `https://kavyayadav05.github.io/My_portfolio/`.
